# Project Euler: Computational Mathematics & Algorithmic Optimization

This repository contains C++ solutions for [Project Euler](https://projecteuler.net/), a series of challenging mathematical/computer programming problems. My approach focuses on bridging theoretical number theory with high-performance software engineering, specifically targeting algorithmic efficiency and robust memory management.

### 🧠 Core Concepts & Methodology
I prioritize **algorithmic complexity reduction**, transforming exponential mathematical conjectures into optimized linear or logarithmic software solutions. Key methodologies include **Dynamic Programming** for state-space reduction, **Object-Oriented Library Design** for reusable mathematical engines (e.g., Prime Sieve/Caching), and **Recursive Search Patterns**. These projects demonstrate a commitment to C++ best practices, including RAII (Resource Acquisition Is Initialization), type safety with `size_t`, and efficient file I/O parsing for large-scale numerical datasets.

### 📂 Problem Index

* **[Problem 6: Sum Square Difference](https://projecteuler.net/problem=6)**
    * Iterative series summation, 64-bit integer overflow prevention, and dynamic command-line argument parsing.
* **[Problem 11: Largest Product in a Grid](https://projecteuler.net/problem=11)**
    * 2D matrix traversal, multi-directional spatial logic, and rigorous boundary-checking to prevent memory segmentation faults.
* **[Problem 18 & 67: Maximum Path Sum](https://projecteuler.net/problem=18)**
    * Bottom-up Dynamic Programming, memoization, and custom destructor logic for non-linear graph memory management.
* **[Problem 42: Coded Triangle Numbers](https://projecteuler.net/problem=42)**
    * String-to-ASCII transformation, custom CSV parsing, and procedural generation for mathematical sequence verification.
* **[Problem 46: Goldbach's Other Conjecture](https://projecteuler.net/problem=46)**
    * Modular class design, "Just-In-Time" prime generation, and recursive binary search for $O(\log n)$ verification.
* **[Problem 50: Consecutive Prime Sum](https://projecteuler.net/problem=50)**
    * Sliding window algorithm, algorithmic pruning for large datasets, and cache pre-population for high-speed summation.
