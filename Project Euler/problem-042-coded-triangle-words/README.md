# Project Euler #42: Coded Triangle Numbers

Solution for [Project Euler #42](https://projecteuler.net/problem=42). This program reads a list of words, converts each word into a numerical score based on alphabetical position (e.g., SKY = $19 + 11 + 25 = 55$), and determines how many of these scores are "triangle numbers."

### 📐 The Mathematics
A triangle number is generated by the formula:
$t_n = \frac{1}{2}n(n+1)$

The sequence begins: $1, 3, 6, 10, 15, 21, 28, 36, 45, 55, ...$

### 🛠 Technical Highlights
* **Mathematical Verification Loop:** Implemented a robust `is_triangle` function that generates triangle numbers on-the-fly to verify if a word's score exists within the sequence, optimizing memory by not pre-generating unnecessarily large datasets.
* **Dataset Parsing:** Utilized `std::ifstream` and `std::getline` with custom delimiters to parse a comma-separated value (CSV) file containing nearly 2,000 words.
* **String Manipulation:** Developed logic to clean input data (removing quotation marks) and transform characters into integer scores based on their ASCII offsets.
* **Scalable Architecture:** The program is designed to accept an external file path as a command-line argument, making it adaptable to any list of words beyond the original problem set.
