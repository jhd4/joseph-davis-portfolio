# Computational Permutation Group Explorer

A Python package for computational finite group theory, implementing disjoint cycle canonicalization, functional permutation composition, and subgroup generation via algebraic closure. Used to computationally analyze and enumerate subgroup structures within the symmetric group $S_5$.

---

## Architecture & Design

The library utilizes a three-layer object-oriented design to model permutation group structures:

* **`Cycle` (`cycle.py`)**: Represents a single cyclic permutation. Automatically normalizes cycle representations upon initialization by cyclically shifting elements until the minimal element is positioned first, and implements evaluation mapping via `__call__`.
* **`Permutation` (`permutation.py`)**: Represents elements of $S_n$ as products of disjoint cycles. Overloads multiplication (`*`) to perform right-to-left functional composition $(\sigma \cdot \tau)(x) = \sigma(\tau(x))$.
* **`Permutation_Group` (`permutation_group.py`)**: Constructs the full algebraic closure $\langle G \rangle$ generated by a set of permutations through iterative composition until no new elements are generated.

### Extensional Equality Verification
Rather than evaluating equality based on cycle syntax or string representation, `Permutation` implements extensional equality in `__eq__`. Two permutations $\sigma$ and $\tau$ are evaluated over their active domain $[\min, \max]$, returning `True` if and only if $\sigma(x) = \tau(x)$ for all $x$. This guarantees that algebraically identical permutations are recognized as equal regardless of cycle order or notation variants.

---

## Subgroup Closure Algorithm

The `Permutation_Group` class computes the complete group generated by a set of input permutations $G = \{g_1, g_2, \dots, g_k\}$:

1. Initialize the member list with the given generators $G$.
2. Iterate through each element $A$ in the member list and compute products $A \cdot B$ and $B \cdot A$ for all members $B$.
3. For each product, check containment in the current member set using extensional equality.
4. Append any new unique permutations and repeat the iteration until no additional elements are produced.
5. Set `self.order` to the length of the fully closed member list.

## Case Study: Enumerating Subgroups of $S_5$

The script `experimental_group_searching.py` searches combinations of three 2-cycles (transpositions) in $S_5$ to isolate subgroups of order 12.

### Computational Result
Running the generator search across all transposition triples identifies exactly 10 distinct subgroups of order 12. Sample generated output:

```text
Group of order 12 generated by (1,2), (1,3), and (4,5)
Group of order 12 generated by (1,2), (1,4), and (3,5)
...
Found 10 groups of order 12
```

## Usage

```python
from permutation_group_library.cycle import Cycle
from permutation_group_library.permutation import Permutation
from permutation_group_library.permutation_group import Permutation_Group

# Define generating transpositions
c1 = Permutation([[1, 2]])
c2 = Permutation([[1, 3]])
c3 = Permutation([[4, 5]])

# Generate group closure
group = Permutation_Group([c1, c2, c3])
print(f"Order: {group.order}")  # Outputs: Order: 12
